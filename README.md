# Recommender Application

A recommendation system that provides investment recommendations to investors.

## Prerequisites

- Python 3.12.7
- Install requirements

## Set-up Instructions
### 1. On the terminal navigate to project folder and checkout feature branch

### 2. To isolate projects dependencies, create a virtual environment
```bash
python -m venv myenv
```

### 3. Activate virtual environment
```bash
source myenv/Scripts/activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```
